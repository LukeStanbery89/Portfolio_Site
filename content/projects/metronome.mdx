# Alternating Tempo Metronome

A web-based metronome designed to help musicians build speed and endurance by alternating between two tempo ratios during practice.

## Features

- **Alternating Tempo Ratios**: Seamlessly switch between two tempos to train your brain and hands for speed transitions
- **Precise Timing**: Built on the Web Audio API for sample-accurate beat scheduling
- **Clean UI**: Minimal, distraction-free interface so you can focus on playing

## Use Cases

Perfect for:
- Practicing fast passages by alternating between a target tempo and a slower resting tempo
- Building endurance through structured speed training
- Gradually pushing your top speed over time

## Technology Stack

- **React**: Component-based UI
- **TypeScript**: Type-safe development
- **Web Audio API**: High-precision timing for accurate beat generation
